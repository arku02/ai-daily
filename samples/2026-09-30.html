OpenAI 推出 Dots：永遠在線、在背景做事的 Agent

HN 608 分產品發布OpenAI DevDay

摘要

OpenAI 在 9/29 的 DevDay 發表 Dots，底層模型是 GPT-6 Astra。每個 Dot 有自己的雲端電腦和瀏覽器，可以連接超過 4,000 個 App，在背景持續追一個目標。它會主動回報進度，卡住時也會回頭問你。你可以在 ChatGPT、Slack 或 Teams 裡跟它對話。目前先開放給 ChatGPT Pro 和 Business Premium，第一個 Dot 不另外收費。

重點

  • Agent 的互動方式從「你問、它答」變成「交辦任務，它自己做完再回報」
  • 「每個 Agent 配一台自己的沙盒電腦」已經是大廠的標準做法
  • 一天之內就有人做出開源版：feder-cr/dots（Python，9/29 建立，已有 702 星）

💡 你可以怎麼用

你的自動化流程可以參考這個互動模式。在 LangGraph 裡，用 checkpointer 讓長時間的任務可以中斷後接著做，再用 interrupt() 在需要你決定的地方停下來、傳 Telegram 問你。例如：一個資料清理 Agent 每天自動跑，遇到異常值不自己亂改，而是停下來問你。

來源：TechCrunch · The Next Web · HN 討論（472 則留言） · 開源版 feder-cr/dots

Nvidia 推出 Agent 安全平台：OpenShell 沙盒 + Sentry 晶片監控

HN 225 分Agent 安全開源

摘要

Nvidia 在 9/28 發表 Open Agent Safety Platform，由兩部分組成。OpenShell 是開源的 Agent 執行環境，它在作業系統核心層限制 Agent 能碰哪些檔案、能連哪些網路，而且 Agent 看不到真正的帳密，只有連到允許的服務時，系統才會代為加上。Sentry 則跑在獨立的 BlueField-4 晶片上，從主機外部監控 Agent，發現越界可以在幾毫秒內隔離。Anthropic 也宣布 Claude Managed Agents 會和它整合。

重點

  • 安全限制從「寫在 prompt 裡請 Agent 遵守」變成「由系統強制執行」
  • 可以做到很細的權限，例如「可以透過 API 讀資料，但不能寫入」
  • OpenShell 今天在 GitHub Trending 上 +990 星，總共 1.1 萬星，Apache-2.0 授權

💡 你可以怎麼用

做資料分析 Agent 時，最怕它不小心改到或刪掉正式資料。不一定要導入 OpenShell，但可以先學它的設計：給 Agent 的資料庫帳號只開唯讀權限，帳密放在工具函式裡，不要寫進 prompt。OpenShell 本身有 PyPI 套件，但要先確認有沒有支援 Windows。

來源：TechCrunch · Help Net Security · GitHub NVIDIA/OpenShell · HN 討論

Anthropic 報告：開源模型 GLM-5.3 已經能自己寫出可用的攻擊程式

HN 224 分資安開源模型

摘要

Anthropic 測試了智譜（Z.ai）釋出的開源模型 GLM-5.3。結果顯示，它能針對 Chrome V8 的漏洞寫出可用的攻擊程式，成功率 12%；在人類指引下，約 20 分鐘就能把公開的漏洞通報轉成實際攻擊。它內建的安全限制也很容易被繞過：用誤導性的提示詞有 64% 成功，預先填入推理內容有 92% 成功，直接修改權重則是 100%。

重點

  • 頂尖開源模型的資安能力已經接近商用模型，但沒有商用模型那層防護
  • Anthropic 建議讓防守方也能使用同等級的模型，並由政府進行安全測試

💡 你可以怎麼用

跟你的工作沒有直接關係。不過如果你會在本機跑開源模型處理敏感資料，要記得「模型內建的限制不等於安全」，資料和權限的隔離要自己做。

來源：Anthropic Research · HN 討論

Cloudflare 推出 cf：專門給 Agent 用的 CLI

HN 167 分開發工具

摘要

Cloudflare 把整套 API 包成一個 CLI 工具，而且設計時就把 AI Agent 當成主要使用者。GitHub 上的 cloudflare/cf 一週內累積了 510 星。

Jev：不生成文字，只回答「有型別的判斷」的模型

GitHub 上有 5 個以上相關專案新類型Early Access

摘要

TypeSafe AI 在 9/15 開放 Jev 搶先體驗，它自稱「System One 模型」。Jev 不是 LLM，也不產生文字：你給它一段狀態，再給它一組有型別的問題（例如「這筆是異常嗎？」回答是或否），它會一次平行回答所有問題，每個答案都附上經過校準的信心分數。官方宣稱它比頂尖 LLM 快 40～200 倍，輸入每百萬 token 只要 $0.042、輸出免費，而且「不可能產生幻覺或型別錯誤」。這些都是廠商自己的說法，還沒有第三方驗證。

重點

  • 這一週的 GitHub 新專案裡，有一大串都是圍繞 Jev 做的：程式碼搜尋 jevgrep（1.8k 星）、Agent 監工 foreman，還有模型路由等等
  • 它的定位是 Agent 裡的「快速判斷」元件，需要深入推理時再交給 LLM

💡 你可以怎麼用

這可能是今天跟你最相關的一則。LangGraph 流程裡常有「分類、路由、判斷要不要處理」這類節點，現在多半用 LLM 加結構化輸出來做，又慢又貴。這些節點很適合換成 Jev 試試。可以先挑一個分類節點，比較兩者的準確率、速度和成本。

來源：DataCamp 介紹 · LangChain：用 Jev 建 harness · jevgrep · awesome-typesafe-jev

趨勢：從「一個 Agent」到「管理一整隊 Agent」

本週最明顯的趨勢多 Agent 協作

摘要

這週 GitHub 上有一整批專案都在做同一件事：用一個管理層來協調多個 Coding Agent。

  • paperclip（9.5 萬星，今天 +2,458）：把 Agent 當成公司員工來管理，有組織圖、預算和目標
  • openrig（今天 +737）：用 YAML 定義 Agent 團隊，讓 Claude Code 和 Codex 在同一個系統裡一起工作
  • ZCode（智譜推出，10 天 7.2k 星）、unreal-agent（非同步優先的 harness）

重點

  • 名詞整理：harness 是包住模型的執行框架，例如 Claude Code；rig 或 orchestrator 則是包住多個 harness 的管理層
  • 大家開始在意的是預算上限、治理規則和成本追蹤，而不只是「能不能完成任務」

💡 你可以怎麼用

LangGraph 的 supervisor 模式就是同樣的概念。你的資料分析流程可以拆成「主管 Agent 分派、專家 Agent 執行」：一個負責撈資料、一個負責分析、一個負責寫報告。注意 openrig 目前不支援原生 Windows，要透過 WSL 才能用。

來源：paperclip · openrig · ZCode · unreal-agent

TraceDance：從真實執行紀錄自動產生 Agent 測試（ByteDance）

HF 60 票Agent 評測有程式碼

摘要

Agent 有時候任務完成了，過程中卻做了不該做的事。固定的標準測驗集抓不到這種問題。TraceDance 讓你描述「不想看到的行為」，系統會自動從大量的執行紀錄（trace）中找出發生過的案例，做成專屬的測試集。評測時從紀錄中的「決策點」接著跑，看模型下一步會怎麼做，不需要標準答案，也不用重建整個環境。論文用了 25 萬筆紀錄，產生 107 套測試集。

重點

  • 核心概念：用正式環境的紀錄來產生回歸測試，而不是只靠人工想測試案例

💡 你可以怎麼用

這和你「Agent 評測與監控」的興趣很對得上。LangGraph 搭配 LangSmith 或自己寫的 log 本來就能存 trace。你可以先從小地方做起：每次自動化出錯時，把那段 trace 存下來，改完 prompt 或流程後重跑一次，確認同樣的錯誤沒有再發生。這就是簡化版的 TraceDance。

來源：HF Papers 2609.33295 · GitHub

vectorize-io/hindsight：會「從經驗學習」的 Agent 記憶系統

今天 +2,575 ⭐總共 4.3 萬PythonMIT

摘要

大部分 Agent 記憶系統做的是「記住對話內容」，Hindsight 的目標是讓 Agent「從經驗中學習」。它宣稱在長期記憶任務上勝過 RAG 和知識圖譜，也附上了論文和公開的評測結果。

重點

  • 提供 Python 內嵌模式，不用架伺服器就能用；也能透過 LLM wrapper 只加 2 行程式接上
  • 有 MCP server，也支援 Coding Agent 整合

💡 你可以怎麼用

如果你的自動化 Agent 每次執行都從零開始，例如每次都重新摸索同一份報表的格式，可以加上 Hindsight，讓它記住上次學到的東西，像是「這個欄位常有空值」「這個來源週一會延遲」。

來源：GitHub · 論文 · 文件

VectifyAI/PageIndex：不用向量資料庫的 RAG

今天 +835 ⭐總共 3.8 萬PythonMIT

摘要

PageIndex 的主張是：向量檢索找的是「相似」的段落，但「相似」不等於「相關」。所以它不切塊、也不用向量資料庫，而是替文件建一個像目錄一樣的樹狀索引，讓 LLM 像人一樣「看目錄、翻到對的章節」。8 月推出的 SDK 可以完全在本機執行。

重點

  • 適合長篇、結構清楚的專業文件，例如財報、法規、技術手冊
  • 安裝：pip install -U pageindex，本機模式用你自己的 LLM API key 就能跑

💡 你可以怎麼用

做資料分析常要從很長的 PDF 報告裡找數字。拿一份你之前用傳統 RAG 效果不好的長文件，換成 PageIndex 試試看，比較回答的準確度。

來源：GitHub

dream-num/univer：給 AI Agent 用的 Office 元件

今天 +696 ⭐總共 2.2 萬TypeScriptApache-2.0

摘要

Univer 是開源的 Office SDK，包含試算表、文件、簡報、PDF 等元件，最近開始主打「AI Agent 的 Office 執行環境」。它有公式引擎，瀏覽器和 Node.js 都能用，文件也有繁體中文版。

重點

  • Agent 可以用程式直接操作試算表，不用去模擬 Excel 介面

💡 你可以怎麼用

如果你的自動化最後要交出 Excel 報表，而且希望使用者能在網頁上直接看、直接改，可以用它來做報表的展示層。它是 TypeScript，Python 那端只要負責產生資料。

來源：GitHub
